# odinsbane.com

Static author site for Nikolai Sie. Plain HTML/CSS/JS, no build step needed to serve it.

## Run locally

```
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Editing

Pages are generated by `tools/build.py`, which holds the shared header/footer and page content.
Story text lives in `tools/content/<slug>.html`. After editing, rebuild and commit the generated HTML:

```
python3 tools/build.py
```

Styles: `assets/style.css`. Scripts (mobile menu, fade-in, contact form): `assets/site.js`.

## Deploying

Hostinger pulls this repo into `public_html` on every push to `main` (hPanel → Git, with a GitHub webhook).
`.htaccess` handles the www redirect, old WordPress URLs, the 404 page and caching.

The contact form posts to FormSubmit (formsubmit.co), which emails nikolai.sie@gmail.com.
The mailing-list form is not connected yet.
